# COLD_NEWS_TG - бот для отслеживания Telegram-каналов по интересующим вас темам.

📌 Как это работает:
1. Выбираете темы - например, криптовалюта, IT или наука
2. Я анализирую новые посты из добавленных вами каналов
3. Присылаю уведомления, когда нахожу посты по вашим темам

⚡️ Все просто - вы получаете только то, что вам действительно интересно!
