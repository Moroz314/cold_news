## 🚀 О проекте

**COLD NEWS** - это мощный Telegram бот, который использует искусственный интеллект для автоматической классификации новостей из ваших Telegram каналов. Больше не нужно manually просматривать десятки каналов - бот сам отсортирует новости по вашим темам и пришлет только то, что действительно важно для вас.

### 🎯 Ключевые возможности

| Функция | Описание |
|---------|-----------|
| **🤖 Умная сортировка** | GigaChat автоматически классифицирует новости по вашим темам |
| **🔔 Персональные уведомления** | Получайте уведомления только по релевантным темам |
| **📊 Гибкая настройка** | Создавайте собственные темы и настраивайте фильтры |
| **🔍 Расширенный поиск** | Ищите посты по ключевым словам во всех каналах |
| **⚡ Real-time мониторинг** | Мгновенная обработка новых постов |

## 🛠 Технологии

**Стек проекта:**
- **Backend:** Node.js + Express
- **База данных:** MongoDB + Mongoose
- **AI:** GigaChat API для классификации
- **Telegram:** Telegraf.js
- **Деплой:** Docker готовность

## 🧠 Интеграция с GigaChat

Бот использует нейросеть GigaChat для:
- 📊 Классификации новостей по темам
- 🎯 Определения релевантности контента
- 🔍 Анализа содержания постов
- ⚡ Быстрой обработки в реальном времени
