# COLD_NEWS_TG - бот для отслеживания Telegram-каналов по интересующим вас темам.

📌 Как это работает:
1. Выбираете темы - например, криптовалюта, IT или наука
2. Я анализирую новые посты из добавленных вами каналов
3. Присылаю уведомления, когда нахожу посты по вашим темам

⚡️ Все просто - вы получаете только то, что вам действительно интересно!

# Описание Telegram-бота для мониторинга и классификации контента

Общее назначение
Этот Telegram-бот предназначен для автоматического мониторинга указанных каналов, классификации публикуемого контента по заданным темам и сохранения результатов в базу данных MongoDB.

Основные функции

  Мониторинг Telegram-каналов
  Бот отслеживает новые сообщения в каналах которые мы добавим в код бота
  Классификация контента
  Каждое новое сообщение автоматически анализируется с помощью API GigaChat и классифицируется по одной из заданных тем пользователем

Управление темами
Пользователи могут:

  - Просматривать доступные темы
  - Добавлять новые темы
  - Удалять существующие темы
  - Получать посты по выбранной теме

Управление каналами
Пользователи могут:

  - Добавлять новые кааналы для мониторинга
  - Удалять существующие кааналы
  - Получать список просматриваемых ими каналов

Хранение данных
Все посты сохраняются в MongoDB с указанием:

  - Текста сообщения
  - Даты публикации
  - Источника (канала)
  - Определенной темы
  - Ссылки на оригинальный пост

Техническая реализация:

  Используемые технологии:
  
    1. Node.js - среда выполнения 
    2. Telegram Client API - для работы с Telegram
    3. MongoDB - база данных для хранения постов и пользовательских настроек
    4. GigaChat API - для классификации контента
    5. Mongoose - ODM для работы с MongoDB
    6. Axios - для HTTP-запросов
