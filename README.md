📰 О проекте

COLD NEWS - это интеллектуальный Telegram бот для мониторинга и сортировки новостей из ваших Telegram каналов. Бот использует нейросеть GigaChat для автоматической классификации новостей по вашим темам и отправляет уведомления только о релевантном контенте.
✨ Основные возможности
🎯 Умная сортировка новостей

    Создавайте собственные темы для новостей

    Добавляйте Telegram каналы для мониторинга

    Автоматическая классификация новостей с помощью нейросети GigaChat

    Получайте уведомления только по интересующим темам
